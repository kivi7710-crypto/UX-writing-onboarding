# UX-writing-onboarding
🌷 StudyNest – UX Writing Exercise

UI/UX Design Project

📌 Project Overview

This project focuses on improving the onboarding experience of StudyNest, a student productivity app concept.

The objective is to rewrite onboarding content using shorter, clearer and more user-friendly language.

✨ Onboarding Screens

1. Plan Your Day

Helps users understand how to organize their daily tasks.

2. Save Your Ideas

Introduces the note-taking feature.

3. Track Your Progress

Shows users how they can monitor their progress.

✍️ UX Writing Principles

- Clarity: Use simple and understandable language.
- Conciseness: Remove unnecessary words.
- Consistency: Maintain a consistent writing style.
- Friendly Tone: Make the experience welcoming.

🧪 Usability Testing

The onboarding flow is designed to be tested with three people.

Testing focuses on:

- Understanding the app's purpose.
- Understanding each onboarding screen.
- Understanding the action buttons.

Actual participant feedback and improvements will be documented after testing.
